# Embeddings Dataset

This directory contains embeddings-related datasets for the leads matching system.

## Purpose

This folder is reserved for:
- Pre-computed embeddings datasets
- Embedding evaluation datasets
- Benchmark embeddings
- Domain-specific embedding collections

## Related Files

- Model: `../model/` - Embedding model files
- Service: `../service.py` - TalentEmbeddingService
- FAISS indices: `backend/embeddings/*.faiss`
